	Once you go to loan details. You find Red highlighted summary box with policy lapse information 
		LP box allows a user to identify Lender Placement for a prior term that needs to be adjusted,cancelled and manual LP adjustment via the Lender Placed Summary box.
		
Tab: Transaction History [ Displays all payment refunds claims and LP transactions]

	Add – the action taken when LP Insurance needs to be started.
	Terminate – the action taken when a preferred policy has been received but LP Do remain active prior to the policy’s effective date
	Flat Cancel – the action taken when preferred policy has been received for the duration LP was active
	Lapse – (in coverage) the time preferred coverage was not active or is not on file

Screen - Exposure Analysis: Displays the requirements for LP
	Full Exposure – The type of LP when no preferred coverage is on file for that time period
	Insufficient – (or insufficiency) the type of LP when preferred coverage is on file but does not meet the required coverage amount
	Required Coverage Amount – The amount of coverage required for the property, found in Exposure Analysis
